# Serving oarlock.sh

`bun run build` writes a fully static site to `dist/`. Serve that folder with any web server; this file lists what the server has to add.

**Implementation:** `deploy/nginx/default.conf` and `deploy/nginx/security-headers.conf` implement these rules in the production image (`deploy/Dockerfile`, nginx-unprivileged on :8080), and `tests/image.sh` proves each row of this file against the built image. Where this file and the config disagree, this file wins and the config is fixed.

## Response headers

Every HTML page already carries a hashed `script-src`/`style-src` Content-Security-Policy in a `<meta>` tag (generated by Astro, finished by `scripts/csp.mjs`). Send these headers on every response as well:

| Header | Value | Why |
| --- | --- | --- |
| `Content-Security-Policy` | `frame-ancestors 'none'` | The one directive a `<meta>` CSP can't express. Browsers enforce both policies. |
| `Strict-Transport-Security` | `max-age=31536000; includeSubDomains` | HTTPS only. |
| `X-Content-Type-Options` | `nosniff` | Required for `/install` to be treated as text. |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | |
| `Permissions-Policy` | `camera=(), microphone=(), geolocation=()` | |
| `Cross-Origin-Opener-Policy` | `same-origin` | |

## Paths that need special handling

| Path | Rule |
| --- | --- |
| `/install` | `Content-Type: text/plain; charset=utf-8` (the file has no extension), `Cache-Control: no-cache` so fixes reach users immediately. Must be served over HTTPS without redirects to other hosts; `curl -fsSL` follows redirects but users read the URL. |
| `/_astro/*` | `Cache-Control: public, max-age=31536000, immutable` (file names are content-hashed). |
| `*.html`, `/` | `Cache-Control: no-cache` or a short max-age. |
| Unknown paths | Serve `/404.html` with status 404. |
| `www.oarlock.sh` | Permanent redirect to `https://oarlock.sh`. |

Directory URLs (`/docs/`, `/roadmap/`) map to `index.html` inside each folder, which every common static server does by default.

## Caddy example

```caddyfile
www.oarlock.sh {
	redir https://oarlock.sh{uri} permanent
}

oarlock.sh {
	root * /srv/oarlock.sh
	encode zstd gzip

	header {
		Strict-Transport-Security "max-age=31536000; includeSubDomains"
		Content-Security-Policy "frame-ancestors 'none'"
		X-Content-Type-Options "nosniff"
		Referrer-Policy "strict-origin-when-cross-origin"
		Permissions-Policy "camera=(), microphone=(), geolocation=()"
		Cross-Origin-Opener-Policy "same-origin"
		-Server
	}

	@install path /install
	header @install Content-Type "text/plain; charset=utf-8"
	header @install Cache-Control "no-cache"

	@hashed path /_astro/*
	header @hashed Cache-Control "public, max-age=31536000, immutable"

	file_server

	handle_errors 404 {
		rewrite * /404.html
		file_server
	}
}
```

## nginx example

```nginx
server {
    listen 443 ssl http2;
    server_name oarlock.sh;
    root /srv/oarlock.sh;

    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header Content-Security-Policy "frame-ancestors 'none'" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;
    add_header Cross-Origin-Opener-Policy "same-origin" always;

    location = /install {
        default_type text/plain;
        charset utf-8;
        add_header Cache-Control "no-cache" always;
        # add_header in a location replaces the server-level ones, so repeat them.
        add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
        add_header Content-Security-Policy "frame-ancestors 'none'" always;
        add_header X-Content-Type-Options "nosniff" always;
        add_header Referrer-Policy "strict-origin-when-cross-origin" always;
        add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;
        add_header Cross-Origin-Opener-Policy "same-origin" always;
    }

    location /_astro/ {
        add_header Cache-Control "public, max-age=31536000, immutable" always;
        add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
        add_header X-Content-Type-Options "nosniff" always;
    }

    error_page 404 /404.html;
}
```

## When to rebuild

The site is static, but two things come from the network at build time:

- **`/roadmap/`** renders `ROADMAP.md` from `qopsc/oarlock@main`. If GitHub is unreachable, the build uses `src/content/roadmap-snapshot.md` and logs a warning.
- Nothing else. Download links use GitHub's `/releases/latest/download/<stable-name>` URLs, and the install script resolves the latest release when it runs, so **a new Oarlock release does not need a site rebuild**.

Rebuild when this repo changes, and occasionally (a daily cron, or a webhook on pushes to `qopsc/oarlock` that touch `ROADMAP.md`) to keep the roadmap fresh.

## Checking a deploy

```sh
curl -sI https://oarlock.sh/install | grep -i content-type          # text/plain
curl -fsSL https://oarlock.sh/install | bash -s -- --dry-run        # parses and plans
curl -sI https://oarlock.sh/ | grep -i -e content-security -e strict-transport
```
