Oarlock is a lightweight, open-source, terminal-first AI workspace built on Tauri 2, Rust, and React. It combines a GPU-drawn terminal, an agentic AI side panel that runs on your own keys or fully local models, a code editor, a file explorer, source control with a git graph, and a web preview pane. No telemetry. No account.
